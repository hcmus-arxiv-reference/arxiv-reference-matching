## Tái lập và nhận dữ liệu

Cần checkout chuỗi PR Normalize #44 → BibTeX #46 → đo #56; validator #55 đã merge vào Normalize.
Cài `requirements.txt` và tải bộ mẫu chung bằng công cụ `scripts.m2_sample`.
Thư mục đang dùng trên máy là `data/m2-sample`. Không đưa token hoặc dữ liệu vào git.

Sau khi có bộ mẫu đã xác minh, chạy từ gốc repo (PowerShell dùng Python của môi trường đã cài):

```powershell
python -m scripts.recover_bibtex_sources --sample configs/m2-sample-100.json --data-dir data/m2-sample --archive-dir data/m2-bibtex-audit/archives --output-dir data/m2-bibtex-supplement --roots configs/m2-reviewed-roots.json
python -m scripts.measure_bibtex --data-dir data/m2-sample --sample configs/m2-sample-100.json --roots configs/m2-reviewed-roots.json --supplement-dir data/m2-bibtex-supplement --artifacts-dir data/m2-bibtex-handoff --output metrics/bibtex.json
```

Khôi phục cần `CONTACT_EMAIL` trong `.env`, tải tuần tự từ `export.arxiv.org`, giãn cách ≥3 giây.
Archive đã lưu được dùng lại. Công cụ từ chối archive lệch receipt và sidecar bị đổi checksum.
Ba root được review nằm trong `configs/m2-reviewed-roots.json`; mỗi quyết định gắn với receipt,
file SHA-256 và lý do. Không sửa source để ép qua Parser.
